## 💡 跨领域洞察

### 决策模型的价值不只在“会行动”
Actor, Judge, or Teacher? 表明决策模型作为 actor 时可能被简单子目标带偏，但作为看完整轨迹的 judge 或 teacher 能提供有效信号；这与 The Value of Thinking 将“何时思考”建模为价值估计相呼应，说明决策模型的能力评估应扩展到评判、教学与成本路由。

### 自进化开始强调验证门控与经验工件学习
FGSE 在经验写入持久记忆前加入证伪与回归探针，Experience-Handoff RL 则把 playbook 等经验交接工件的构建本身纳入 RL；两者共同显示，自进化系统的关键正从“直接写记忆/反思”转向“可验证地提交经验”。

### Agent 效率优化同时覆盖推理路由与量化蒸馏
The Value of Thinking 通过 zero-or-T 路由控制显式推理开销，SteerDistill 通过闭环教师修正降低量化 agent 的行为偏差；一条面向部署效率、一条面向低比特部署可靠性，均直接服务 agent 落地成本。

### 本周 Coding Agent 学术信号偏弱，框架侧集中在模型与决策任务接入
本周入选论文中没有仓库级软件工程或 SWE-bench 方向的强信号；框架更新主要体现为 ms-swift 扩充模型支持并增加 typed-decision / JEV 决策任务能力。

## 📚 🧠 强化学习 (RL)

### 🌟 强烈推荐

#### [The Value of Thinking: Learning When to Reason in Hybrid Decision Models](https://huggingface.co/papers/2611.16961)

**作者**: Zhengxu Yu, Ke Xu, Meng Fang et al. | **发布**: 2026-11-12

*<sub>📊 评分明细: 权威 20 | 相关 28 | 时效 20 | 分类 9 | 热度 7 ➔ **总分: 84**</sub>*

提出 zero-or-T thinking 与 HDM：同一冻结骨干由轻量自路由块估计“思考价值”，在隐式单次前向与完整自回归推理间选择；无逐决策标签时用 CDPO 从 episode 回报训练路由。在 MMLU-Pro、AGIEval、GPQA-Diamond、JevBench 等评估，JevBench 上 HDM-4B 达 0.857。

**技术亮点**: 零 token 隐式思考与 T token 显式推理并存；自路由块估计慢模式相对快模式的期望增益并按价格 λ 决策；CDPO 使用 episode-level return 训练路由。

**落地难度**: High

## 📚 🤖 Agentic RL / 多智能体

### 🌟 强烈推荐

#### [Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents](https://huggingface.co/papers/2611.17167)

**作者**: Haochen Liu, Qianhao Zhu, Zixuan Wang et al. | **发布**: 2026-11-12

*<sub>📊 评分明细: 权威 20 | 相关 28 | 时效 20 | 分类 9 | 热度 7 ➔ **总分: 84**</sub>*

研究决策模型作为 actor 之外的 judge/teacher 价值：在 ALFWorld 比较三类决策模型与三类通用 LLM，并用 JEV 在 ALFWorld/WebShop 教学。结果显示模型作 actor 易被简单子目标带偏，但看完整轨迹作 judge 能正确归因；JEV 作 teacher 将 Qwen2.5-1.5B+GRPO 从 72.8% 提至 82.9%（ALFWorld），从 56.8% 提至 71.4%（WebShop）。

**技术亮点**: 用 JEV 作 teacher 给动作打分；判断“该动作是否有帮助”比判断任务是否成功更能区分有用/无用动作；结合 GRPO 提升小模型策略。

**落地难度**: Medium

### 📖 值得知道

- **[When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents](https://arxiv.org/abs/2611.14326)**: 提出 FGSE，用验证器门控决定经验教训何时写入持久 agent 状态，并在 web/app/tool-use/记忆基准上降低错误更新。
  - 💡 适合需要长期记忆/持续学习的 LLM agent，在写记忆前加入验证门控与回归探针。
- **[S1-Evo: Experience-Guided Evidence Competition Attacks on Typed System-1 Decision Models](https://arxiv.org/abs/2611.16937)**: 提出 S1-Evo，针对 typed System-1 决策模型，通过 contract-aware evidence competition 自进化搜索攻击扰动。
  - 💡 用于 typed decision / LLM agent 路由与授权模块的红队评估，重点关注不可信上下文字段。
- **[SkillEarth: Teaching General-Purpose Agents to Act on Earth via Skill Evolution](https://arxiv.org/abs/2611.15481)**: 提出 SkillEarth，从示范轨迹自动抽取并演化遥感工具调用技能文件，无需专家干预或参数更新。
  - 💡 可借鉴到工具型 agent 的技能库构建与持续演化，但需自行验证跨任务泛化。

## 📚 🔄 RSI / 自进化

### 🌟 强烈推荐

#### [Experience-Handoff Reinforcement Learning for Recursive Self-Improvement](https://huggingface.co/papers/2611.16409)

**作者**: Doyoung Kim, Byeongguk Jeon, Kailin Zhang et al. | **发布**: 2026-11-12

*<sub>📊 评分明细: 权威 20 | 相关 30 | 时效 20 | 分类 10 | 热度 9 ➔ **总分: 89**</sub>*

针对现有 agent harness 通过 reflection/compaction 传递经验但交接工件构建不可学习的问题，提出经验交接 RL：固定 Agentic Context Engineering harness，训练一个模型同时作为 actor、reflector、playbook curator，并以候选工件对未来 actor rollout 的下游效果评估、联合优化角色行为。在 agentic benchmarks 上 held-out 性能高于基线。

**技术亮点**: 用标量奖励梯度更新，同时利用环境细粒度信息生成可交接经验；以未来 rollout 效果评价经验工件；在固定 scaffold 下 co-optimize 多角色行为。

**落地难度**: High

### 📖 值得知道

- **[Prior-as-Skill: Remember Outside and Read Inside with On-Policy Self-Distillation for Self-Evolving VLM Agents](https://arxiv.org/abs/2611.15766)**: 提出 PriorSplit，在 OPSD 技能内部化之外保留顺序先验，以应对外部帧缺失/顺序异常。
  - 💡 适合视觉/多步 agent 部署时处理帧缺失与步骤重排，但需注意其视觉任务背景，不涉及机器人硬件。
- **[AskALCF: A Self-Improving Agentic System for Intelligent HPC User Support](https://arxiv.org/abs/2611.15700)**: 提出 AskALCF，面向 HPC 用户支持的 agentic 日志分析与自改进管线，细粒度归因失败并路由修复。
  - 💡 适合生产级 agent 支持系统的失败归因、持续修复与上线门控。

## 🏆 值得深入阅读的 Top Papers

1. **[Experience-Handoff Reinforcement Learning for Recursive Self-Improvement](https://huggingface.co/papers/2611.16409)**
   > 本周最高分学术论文。将经验交接工件的构建纳入 RL，并联合优化 actor、reflector、playbook curator，直接指向递归自我改进闭环。

2. **[The Value of Thinking: Learning When to Reason in Hybrid Decision Models](https://huggingface.co/papers/2611.16961)**
   > 提出 zero-or-T thinking 与 HDM，将“何时思考”建模为价值估计，并用 CDPO 从 episode 回报训练路由。对 agent 推理成本控制有直接价值。

3. **[Actor, Judge, or Teacher? Understanding Decision Models in Long-Horizon Agents](https://huggingface.co/papers/2611.17167)**
   > 系统比较决策模型作为 actor/judge/teacher 的角色，证明差 actor 仍可能作好 teacher。JEV 教学结合 GRPO 在 ALFWorld/WebShop 上展示明确增益。

4. **[When Should Agents Remember? Falsification-Gated Self-Evolution for LLM Agents](https://arxiv.org/abs/2611.14326)**
   > 用证伪门控决定经验是否进入持久状态，针对 agent 长期记忆的安全写入问题。实验覆盖多个 agent 基准，并报告错误更新与回归损害下降。

5. **[SteerDistill: Quantizing LLM Agents via Closed-Loop Teacher Steering](https://huggingface.co/papers/2611.13410)**
   > 面向量化 LLM agent 的闭环教师蒸馏，在低比特下缩小与 BF16 的差距。部署价值明确，适合成本敏感型 agent 推理。

6. **[Prior-as-Skill: Remember Outside and Read Inside with On-Policy Self-Distillation for Self-Evolving VLM Agents](https://arxiv.org/abs/2611.15766)**
   > 关注自进化视觉 agent 的内部化与外部先验拆分，对帧缺失与步骤顺序异常场景有针对性。属于 self-evolving agent 的训练闭环线索。

7. **[AskALCF: A Self-Improving Agentic System for Intelligent HPC User Support](https://arxiv.org/abs/2611.15700)**
   > 生产级自改进诊断管线，强调失败归因与可执行修复。2,174 条支持对话中不可归因失败显著下降，工程参考价值较强。

8. **[SkillEarth: Teaching General-Purpose Agents to Act on Earth via Skill Evolution](https://arxiv.org/abs/2611.15481)**
   > 从示范轨迹外化并演化工具调用技能，面向动态工具环境中的持续适应。可作为工具型 agent 技能库构建的参考。

9. **[S1-Evo: Experience-Guided Evidence Competition Attacks on Typed System-1 Decision Models](https://arxiv.org/abs/2611.16937)**
   > 针对 typed System-1 决策模型的自进化攻击框架，揭示 LLM agent 路由、审核与授权模块的安全风险。对 agent 安全评估有警示意义。
