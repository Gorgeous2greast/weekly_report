# 🤖 AI 前沿周报 - 2026-10-31

## 📌 执行摘要

- 🧠 **强化学习 (RL)**: 本周 RL 侧最突出的是在线 PPO 训练在真实 iOS UI 导航中的落地：引入 step-level advantage 与 GiGPPO 邻域条件价值估计，并用 LLM-as-a-Judge 构造稠密步级奖励与终端奖励，在多个基准上优于 SFT 和仅终端奖励基线。
- 🤖 **Agentic RL / Coding Agent**: Agentic RL 本周集中在真实代码验证与工具/界面接口：EasyProver 用递归隔离上下文智能体在 Lean 证明任务上接近饱和，MICA 证明 MCP/CLI 表示会显著改变智能体行为并可定向修复。
- 🏋️ **LLM 训练/对齐**: Training Foundation Models with a Single Algorithm 提出用统一似然训练把预训练、SFT、RL 等阶段纳入同一算法与训练器，改善精度-计算权衡与任务覆盖。
- 🔄 **RSI / 自进化**: Youtu-Parsing-Omni 的 OSAD 让解析器在自己的 rollout 与参考条件目标上迭代、解析器与监督共同演化，是本周最明确的自进化训练闭环。
- 🛠️ **训练框架动态**: 本周无重要框架更新。

## 💡 跨领域洞察

### Agentic RL 正从静态轨迹拟合走向在线真实环境与接口级干预
Online Dense RL 直接在 live iOS 应用上训练，MICA 将 MCP/CLI 接口表示视为闭环决策环境的一部分，EasyProver 用递归智能体处理真实实现级 Lean 验证任务；三者共同表明智能体能力不仅取决于策略和数据，也受环境接口、执行反馈与在线探索机制影响。

### 统一训练与自进化监督正在形成闭环线索
Training Foundation Models with a Single Algorithm 试图用单一似然训练统一预训练、SFT 与 RL；Youtu-Parsing-Omni 的 OSAD 用模型自身 rollout 与参考条件自副本产生 token 级监督并刷新参考权重，使解析器与监督共演化。两者分别从训练算法和自生成监督层面指向更连续、更少阶段割裂的训练范式。

### 金融 Agent 评测从知识问答转向证据链与决策闭环
EPSBench 要求智能体把财务证据连接到利润表驱动项并输出可引用估算，Investor’s Last Exam 则用冻结信息集、专业分析师任务和金融依赖图联合评估研究质量、预测准确性与模拟投资表现；评测单元正从孤立能力转向证据-假设-判断链。

## 📚 🧠 强化学习 (RL)

### 🌟 强烈推荐

#### [Online Dense Reinforcement Learning with Planning-Grounding Agent for UI Navigation on Live IOS Apps](https://huggingface.co/papers/2610.39264)

**作者**: Peitong Duan, Khashayar Gatmiry, Jeffrey Nichols et al. | **发布**: 2026-10-29

*<sub>📊 评分明细: 权威 20 | 相关 30 | 时效 20 | 分类 9 | 热度 8 ➔ **总分: 87**</sub>*

针对 VLM 推理成本高、小模型经 SFT/离线 RL 易记忆静态轨迹且难纠错的问题，提出在真实 iOS 应用上在线 RL 训练 UI 导航智能体：解耦 Planning agent 与 UI Grounding model，用 LLM-as-a-Judge 提供步级稠密反馈和终端奖励，并以 PPO 步级优势估计及 GiGPPO 邻居条件价值估计优化。在 UINavBench、iOSWorld、AndroidWorld 上优于 SFT 和仅终端奖励基线，8B 模型在 Android OOD 上较 SFT 近七倍提升，真实 iOS 上超过 Gemini-3.5-Flash、与 Gemini-3.1-Pro 持平。

**技术亮点**: Planning 与 Grounding 解耦；LLM-as-a-Judge 双奖励结构；PPO step-level advantage estimation；GiGPPO 邻居条件价值估计提升 critic 稳定性；数百并发虚拟 iOS 设备训练基础设施。

**落地难度**: High

## 📚 🤖 Agentic RL / Coding Agent

### 🌟 强烈推荐

#### [Scaling Lean Theorem Proving for Real-World Code Verification](https://huggingface.co/papers/2610.38174)

**作者**: Debargha Ganguly, Divya Raghunathan, Dejan Jovanović et al. | **发布**: 2026-10-28

*<sub>📊 评分明细: 权威 20 | 相关 24 | 时效 20 | 分类 9 | 热度 8 ➔ **总分: 81**</sub>*

针对 Lean 定理证明与真实代码验证需求，提出 EasyProver：由隔离上下文的递归智能体、异步搜索、并行 tactic 探测和弹性 elaboration 服务组成，使用现成前沿模型无需额外训练。其在 PutnamBench 证明 669/672、IMO 2026 全部六个形式化、NTP4VC 597/600 验证条件及 VERINA 全部 189 任务。为缓解基准饱和，构建 Aegis 将竞赛编程题转为真实实现上的更难验证任务，生成 2,045 个差分验证 Rust-Lean 程序对和 11,533 个候选规格；在 2,000 条分层样本上 30 分钟预算内证明 1,054 条（52.7%）。

**技术亮点**: 递归智能体与隔离上下文；异步搜索；并行 tactic 探测；弹性 elaboration 服务；Aegis 自动生成 Rust-Lean 程序对与候选规格，可作为证明器基准和 RL 奖励。

**落地难度**: High

## 📚 🏋️ LLM 训练/对齐

### 🌟 强烈推荐

#### [Training Foundation Models with a Single Algorithm](https://huggingface.co/papers/2610.40564)

**作者**: Yuda Song, Alvin Zhang, Fahim Tajwar et al. | **发布**: 2026-10-29

*<sub>📊 评分明细: 权威 20 | 相关 29 | 时效 20 | 分类 9 | 热度 7 ➔ **总分: 85**</sub>*

指出现有基础模型按预训练、midtraining、SFT、RL 分阶段训练并非本质必要；通过将合适 RL 目标推导为对模型生成目标分布的最大似然拟合，把所有阶段统一到单一似然训练算法 unified training，使训练生命周期转化为选择数据、比例与时机的问题，传统分阶段训练成为特例。实现单训练器混合静态数据与 RL 生成，在受控和真实实验中改善精度-计算权衡与任务覆盖，同时保持更广能力，并为持续学习提供更好起点。

**技术亮点**: 将 RL 目标解释为对模型生成目标分布的最大似然拟合；单训练器混合静态数据与 RL 生成；把 staged training 作为统一框架特例。

**落地难度**: High

## 📚 🔄 RSI / 自进化

### 🌟 强烈推荐

#### [Youtu-Parsing-Omni: One Encoder, One Schema, All Modalities](https://huggingface.co/papers/2610.39301)

**作者**: Yunhang Shen, Zhangquan Chen, Xiaotian Li et al. | **发布**: 2026-10-29

*<sub>📊 评分明细: 权威 26 | 相关 26 | 时效 20 | 分类 8 | 热度 5 ➔ **总分: 85**</sub>*

提出 Youtu-Parsing-Omni 全模态解析器，将文档、图像、音频、视频转为带时空定位的结构化记录，为智能体提供跨模态证据读取、定位与引用感知层；用一个编码器处理所有模态、一个 OmniSchema 统一十项解析任务，并提出 OmniSchema-Aware On-Policy Distillation (OSAD)：每轮用模型自身 rollout 对参考条件自副本的 token 级目标训练，再以训练权重刷新参考，使解析器与监督共同演化。单一 5B checkpoint 在 OmniDocBench v1.6 达 96.96 Overall，在 OmniParsingBench 开放权重模型中领先（75.08 Avg.），优势集中于音频与视频。

**技术亮点**: 单编码器共享权重统一多模态；OmniSchema 统一十项解析任务；OSAD 用自身 rollout、参考条件 token 级目标和权重刷新实现解析器与监督共演化；统一时空坐标与视频帧-音频注意力融合。

**落地难度**: High

## 🏆 值得深入阅读的 Top Papers

1. **[Online Dense Reinforcement Learning with Planning-Grounding Agent for UI Navigation on Live IOS Apps](https://huggingface.co/papers/2610.39264)**
   > 将在线 RL 直接放到真实 iOS 应用上训练 UI 导航智能体，结合 Planning/Grounding 解耦、LLM-as-a-Judge 双奖励、PPO 步级优势估计与 GiGPPO 价值估计，并在多个 UI 基准上优于 SFT 和仅终端奖励基线，是本周 RL 与 Agent 落地的代表工作。

2. **[Training Foundation Models with a Single Algorithm](https://huggingface.co/papers/2610.40564)**
   > 提出统一似然训练视角，将预训练、SFT、RL 等阶段纳入同一算法与训练器，并把训练生命周期转化为数据选择与比例问题；概念和工程价值高，适合关注 LLM 全生命周期训练与持续学习的研究者。

3. **[Youtu-Parsing-Omni: One Encoder, One Schema, All Modalities](https://huggingface.co/papers/2610.39301)**
   > 以单编码器、单 schema 统一十项全模态解析任务，OSAD 用自身 rollout 与参考条件自副本产生 token 级监督并刷新参考权重，形成解析器与监督共演化的自进化训练闭环；同时公开代码权重并在多项解析基准领先。

4. **[Scaling Lean Theorem Proving for Real-World Code Verification](https://huggingface.co/papers/2610.38174)**
   > EasyProver 用递归隔离上下文智能体、异步搜索和并行 tactic 探测在多个接近饱和的 Lean 基准上取得高覆盖率，并构建 Aegis 将竞赛编程题转为真实实现上的更难验证任务，兼具 Agentic RL、形式化验证与 RL 奖励构建价值。

5. **[Investor's Last Exam: Can AI Agents Do Equity Investment Without Seeing the Future?](https://huggingface.co/papers/2610.38342)**
   > 由专业买方投资者设计，强调冻结信息集、专业分析师任务分类和金融依赖图，联合评估研究质量、预测准确性与模拟投资表现；结果揭示前沿模型整体研究能力与预测表现之间存在明显脱节。

6. **[EPSBench: Benchmarking LLM Agents for Earnings Forecasting](https://huggingface.co/papers/2610.38293)**
   > 聚焦季度盈利预测中的会计驱动项与证据引用，共享会计计算器使不同模型的预测假设可比，并系统检查点预测误差与预测区间覆盖，适合作为金融 Agent 评测与不确定性校准基线。

7. **[Matched Capabilities, Different Behaviors: A Controlled Study of MCP and CLI Interfaces for Language Agents](https://huggingface.co/papers/2610.34298)**
   > 在能力匹配条件下系统比较 MCP 与 CLI 接口表示对语言智能体行为的影响，发现接口实现会改变语义动作选择、失败路径与恢复；DART 进一步证明接口级修复可提升性能并降低 token 成本，对工具/Agent 接口设计有直接启发。
